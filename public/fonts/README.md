# پوشه فونت‌های اختصاصی iRamoAi (`public/fonts/`)

این پوشه برای قرار دادن فایل‌های فونت اختصاصی شما (با فرمت `.woff2`، `.woff`، `.ttf` یا `.otf`) آماده شده است.

## نحوه استفاده (کاملاً خودکار):
1. فایل‌های فونت خود (مثلاً Regular، Medium، Bold) را در همین پوشه (`public/fonts/`) داخل گیت‌هاب آپلود کنید.
2. **نیازی به ویرایش دستی کد نیست:** هنگام بیلد در گیت‌هاب اکشنز یا ساخت بسته وردپرس (`scripts/generate-custom-font-css.mjs`)، تمام فایل‌های فونت موجود در این پوشه به‌صورت خودکار شناسایی، وزن‌دهی و در `custom-font.css` فعال می‌شوند.
3. از داخل «پنل مدیریت محتوا ← تنظیمات فونت» (یا پیشخوان وردپرس ← تنظیمات iRamoAi)، گزینه فونت را روی **«فونت اختصاصی»** بگذارید (پیش‌فرض روی `IramoCustomFont` تنظیم شده است و بلافاصله فعال می‌شود).
