# پوشه فونت‌های اختصاصی iRamoAi (`public/fonts/`)

این پوشه برای قرار دادن فایل‌های فونت اختصاصی شما (مثل ایران‌سنس، یکان‌بخ، پیدا، دانا یا هر فونت دلخواه با فرمت `.woff2`) آماده شده است.

## نحوه استفاده:
1. فایل‌های فونت `.woff2` را در همین پوشه (`public/fonts/`) داخل گیت‌هاب قرار دهید.
2. فایل `custom-font.css` همین پوشه را باز کرده و کدهای `@font-face` داخل آن را مطابق نام فایل فونت خودتان از حالت کامنت خارج کنید.
3. از داخل «پنل مدیریت محتوا ← تنظیمات فونت» (یا پیشخوان وردپرس ← تنظیمات iRamoAi)، گزینه فونت را روی **«فونت اختصاصی»** قرار داده و نام `font-family` که در `custom-font.css` تعریف کردید (مثلاً `IramoCustomFont`) را بنویسید.

> هنگام بیلد در گیت‌هاب اکشنز (`npm run package:wp`)، تمام فایل‌های داخل `public/fonts/` به‌صورت خودکار داخل فایل زیپ افزونه وردپرس (`assets/fonts/`) نیز بسته‌بندی و روی سایت لود می‌شوند.
